 So this is basically a little tool I made for myself to keep track of the coding questions I'm practicing, like LeetCode and HackerRank stuff. I kept forgetting what I'd already solved and which topics I was actually weak at, so I just built this in Python to fix that for myself. You can add topics like arrays or loops, then log questions under each one, and when you log a question you also put in how hard it was, today's date gets added automatically, and you can leave a little note if something's worth remembering. There's also a right or wrong option, so if I got something wrong I can write down what went wrong or how I should've approached it, which honestly has been more useful than I expected because I actually go back and read those before tests. Other than that you can view everything you've logged, search for a question if you forget which topic you put it under, sort topics by how many questions you've done, fix a question if you typed something wrong, or delete a topic if you don't need it. I also threw in two small stats things, one shows which day I solved the most questions, and the other shows my percentage correct for each topic, so I can actually see which topics I'm bad at instead of just guessing. Everything saves automatically into a json file so I don't lose my progress every time I close it, and that file isn't pushed to GitHub since it's just my own data, not really part of the actual project. To run it you just need Python and you type python main.py in the terminal, then it gives you a menu and you pick numbers to do stuff. I'm doing this as a first year project while studying computing, mostly just to get better at using dictionaries, functions, and not crashing the program every time someone types something weird, and at some point I want to turn this into an actual website using Streamlit so it looks less like a terminal thing and more like a real app.
